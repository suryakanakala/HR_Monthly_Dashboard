# Monthly HR Dashboard (Excel)

## 📌 Overview
This project showcases a **Monthly HR Dashboard** designed entirely in **Microsoft Excel**.  
It leverages pivot tables, formulas, and custom chart formatting to provide actionable insights into workforce metrics, salary distribution, hiring trends, and employee performance indicators.  

The dashboard was inspired by **Chandoo’s YouTube tutorials** and extended with my own design elements and business logic.

---

## 🎯 Key Features
- **Headcount & FTE Tracking** – Monitor workforce size and full-time equivalents.  
- **Hiring Trends** – Visualize monthly hiring growth (+440 hires in the last 3 months).  
- **Salary Distribution** – Explore salary ranges across departments (e.g., Epsilon).  
- **Employee Segmentation** – Identify staff distribution (45% from Alpha).  
- **Performance Metrics** – Track AIB scores and negative balance cases.  
- **Salary vs Tenure Analysis** – Scatter plot to understand compensation trends.  

---

## 🛠️ Tech Stack
- **Microsoft Excel** for dashboard creation  
- **Pivot Tables & Charts** for dynamic analysis  
- **Formulas (SUMIFS, AVERAGEIFS, etc.)** for calculations  
- **Conditional Formatting** for highlighting insights  
- **CSV/Excel datasets** as source data

## 🚀 How to Use
1. Clone this repository or download the Excel file.  
2. Open the `.xlsx` file in **Microsoft Excel**.  
3. Explore the interactive pivot tables, slicers, and charts.  
4. Replace sample data with your own HR dataset if needed.

This dashboard helps HR teams and leadership:

- Support data-driven HR decision-making.
